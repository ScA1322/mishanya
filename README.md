**Личный бесплатный Discord-бот с веб-панелью: уровни, модерация, автомодерация, приветствия и многое другое.**

### Быстрый старт

```bat
git clone https://github.com/ScA1322/mishanya.git
cd mishanya
setup.bat
```

Затем впишите токен бота в `.env` и запустите `start.bat`. Подробности в разделе [Установка](#установка).

> [!IMPORTANT]
> Файл `.env` с токеном бота и паролем панели исключён из репозитория через `.gitignore`. Не коммитьте его
> и никому не показывайте токен. Если токен всё же утёк, сразу нажмите **Reset Token** в Discord Developer Portal.

## Возможности

**Уровни и XP**
- XP за сообщения: настраиваемые минимум/максимум, множитель, интервал начисления (по умолчанию раз в 60 с).
- Защита от фарма: интервал, минимальная длина сообщения, игнор повторов одного и того же текста.
- Формула уровня `A·L² + B·L + C` (по умолчанию 5/50/100, как у MEE6), максимальный уровень; при смене формулы уровни пересчитываются.
- Уведомления о новом уровне: в текущий канал, выбранный канал, в ЛС или отключены; шаблон с переменными и предпросмотром.
- Исключения: каналы, категории, роли.
- Роли за уровни: любое количество порогов, отключение отдельных наград, режим «накапливать» или «только высшая роль».
  Награда выдаётся только при переходе через уровень и если роли ещё нет — повторной выдачи не происходит.
- Выход и повторное вступление: XP сохраняется (или сбрасывается — настраивается), награды возвращаются при возвращении.
- Ручное изменение XP/уровня (панель и `/xp`), сброс участника и всего сервера, импорт/экспорт JSON.
- `/rank`, `/level`, `/profile`, `/leaderboard` (с перелистыванием), `/rewards`.

**Модерация**: `/kick`, `/ban`, `/unban`, `/timeout`, `/untimeout`, `/warn`, `/warnings`, `/unwarn`, `/clearwarnings`,
`/cases`, `/clear`, `/purge` (фильтры по автору, тексту, ботам), `/slowmode`, `/lock`, `/unlock`, `/nickname`,
`/role add|remove`, `/userinfo`, `/serverinfo`.
- Проверка прав вызвавшего **и** бота при каждом вызове, проверка иерархии ролей, запрет действий над владельцем/собой/ботом.
- Причина, уведомление участника в ЛС (если открыты), нумерованный журнал случаев, канал журнала модерации.
- Предупреждения: история, снятие по номеру, полный сброс, срок действия, автоматические действия
  (тайм-аут/кик/бан) при достижении настраиваемых порогов.

**Автомодерация** (всё выключено по умолчанию): антиспам, антифлуд (строки, длина, повтор символов),
повтор сообщений, массовые упоминания и `@everyone/@here`, запрещённые слова (целое слово или вхождение),
ссылки с белым списком доменов, приглашения Discord с белым списком кодов. Для каждого правила — удаление,
предупреждение в канале, запись предупреждения `/warn`, собственные исключения. Глобальные исключения ролей/каналов,
модераторы не проверяются (отключаемо). Тайм-аут за N нарушений за M минут. Все срабатывания журналируются.

**Приветствия**: сообщение при вступлении, при выходе, приветствие в ЛС; текст и/или embed, переменные, предпросмотр.
Картинка-баннер как в MEE6: аватарка и имя участника, заголовок и подпись с переменными, расположение (по центру
или аватар слева), 8 шрифтов, форма и обводка аватара, цвет текста, фон — цвет, градиент с готовыми палитрами
или своя картинка с затемнением. Предпросмотр в панели рисуется тем же кодом, что и в Discord.

**Автороли**: несколько ролей для участников, отдельные — для ботов, исключённые пользователи, задержка;
удалённые или недоступные роли пропускаются с предупреждением в диагностике.

**Пользовательские команды**: создание в панели, вызов через префикс (`!правила`) или `/cmd правила`
(с автодополнением), текст и embed, переменные, ограничение по ролям и каналам, задержка, ответ в ЛС,
удаление сообщения-вызова, счётчик использований, проверка конфликтов имён. Код не выполняется — только шаблоны.

**Журналы**: удаление/редактирование сообщений, вступление/выход, никнеймы, роли участников, роли сервера,
каналы, настройки сервера, модерация, автомодерация. Для каждого типа — включение и свой канал.
Записи хранятся в базе с ограничением срока и количества; текст сообщений в базу по умолчанию не сохраняется.

**Меню с кнопками**: сообщение в текстовом канале с текстом, embed, загруженным изображением (PNG, JPEG, GIF, WebP до 8 МБ)
и до 25 кнопок. Кнопка может ответить сообщением (видно только нажавшему), выдать или снять роль, открыть тикет
или открыть ссылку. Выпадающий список ролей: участник, зашедший на сервер, сам выбирает себе роль (одну или несколько,
настраивается); выбор другой роли снимает предыдущую. Готовые шаблоны: «Выбор ролей для новичков» и «Поддержка».
Меню публикуется и обновляется из панели; кнопки работают и после перезапуска бота.

**Тикеты**: участник нажимает кнопку в меню (или `/ticket open`), указывает тему — бот создаёт приватный канал,
который видят только автор, роли поддержки и администраторы. Кнопки «Закрыть тикет» и «Взять в работу»,
`/ticket add`/`remove` для добавления участников, лимит открытых тикетов на человека. При закрытии в канал журнала
уходит отчёт и файл-стенограмма переписки, канал удаляется. Список открытых и закрытых тикетов — в панели.

**Музыка (SoundCloud)**: `/play название` или ссылка на трек/плейлист SoundCloud; очередь, `/skip`, `/pause`,
`/resume`, `/stop`, `/queue`, `/nowplaying`, `/shuffle`, `/loop` (трек/очередь), `/volume`. Роли диджея,
лимит очереди и длины трека, автовыход при простое или когда в канале никого нет. В панели — что играет и кнопки
управления. FFmpeg ставится автоматически вместе с зависимостями — отдельно ничего скачивать не нужно.

**Голосовые комнаты**: участник заходит в канал-создатель — бот создаёт ему личный голосовой канал (название по
шаблону, например «🔊 Комната {display_name}», лимит участников, нужная категория) и переносит туда. Когда в комнате
никого не осталось, она удаляется — в том числе после перезапуска бота. Повторный вход в канал-создатель возвращает в
свою комнату, а не создаёт новую. Владелец управляет комнатой прямо в Discord или командами `/voice rename`, `limit`,
`lock`, `unlock`, `kick`; если он ушёл — `/voice claim`. Канал-создатель бот может создать сам из панели, их можно
сделать до 10 на сервер.

**Прочее**: `/help`, `/ping`, `/avatar`, `/poll` (реакции, до 10 вариантов), `/invite`,
`/remind` / `/reminders` / `/unremind` — напоминания хранятся в базе, переживают перезапуск,
пропущенные доставляются с пометкой об опоздании; если канал недоступен — в ЛС.

**Веб-панель**: главная, серверы, обзор сервера, уровни, таблица лидеров, роли за уровни, модерация,
автомодерация, приветствия, автороли, команды, меню с кнопками, тикеты, музыка, журналы, общие настройки,
обновления и резервные копии, диагностика, справка.

## Системные требования

- Windows 10/11.
- **Python 3.12–3.14** (рекомендуется 3.14) — https://www.python.org/downloads/ (при установке отметьте «Add python.exe to PATH»).
  Если установлено несколько версий, `setup.bat` сам выберет подходящую. На Python 3.15 бот работает, но музыка — нет:
  для этой версии ещё не вышел готовый пакет шифрования голосовых каналов Discord (davey).
- Node.js **не обязателен**: собранная панель уже лежит в `frontend/dist`. Он нужен, только если вы меняете код панели
  (Node.js 22 LTS или новее — https://nodejs.org/).
- Около 150 МБ на диске (вместе с зависимостями).

## Установка

1. Склонируйте репозиторий (`git clone https://github.com/ScA1322/mishanya.git`) или скачайте ZIP
   (**Code → Download ZIP**) и распакуйте, например в `D:\mishanya`.
2. Дважды щёлкните **`setup.bat`**. Скрипт:
   - проверит Python;
   - создаст виртуальное окружение `.venv` и установит зависимости;
   - соберёт панель, если найден Node.js (иначе использует готовую);
   - создаст `.env` со случайным паролем панели и **покажет его** (пароль хранится в `.env`);
   - создаст базу данных `data\mishanya.db`;
   - запустит самопроверку (тесты);
   - предложит открыть `.env` в Блокноте.
3. Вставьте токен бота в `.env` (см. следующий раздел).

`setup.bat` можно запускать повторно — существующие `.env` и данные не затираются.

## Настройка Discord-приложения

1. Откройте https://discord.com/developers/applications → **New Application** → назовите «Mishanya».
2. Вкладка **Bot**:
   - **Reset Token** → скопируйте токен → вставьте в `.env`: `DISCORD_TOKEN=ваш_токен`.
     Токен — это пароль бота: не публикуйте его и никому не отправляйте. Если он утёк — снова нажмите Reset Token.
   - **Privileged Gateway Intents** — включите:
     - **Server Members Intent** — приветствия, прощания, автороли, журнал участников, восстановление наград при возвращении;
     - **Message Content Intent** — автомодерация (проверка текста) и команды с префиксом.
     Без них Discord откажет в подключении — панель покажет понятную ошибку.
   - Presence Intent не нужен.
3. Запустите `start.bat`, войдите в панель и на главной странице нажмите **«Пригласить Mishanya на сервер»**
   (ссылка доступна после подключения бота). Ссылку также выдаёт команда `/invite`.
   Вручную: OAuth2 → URL Generator → scopes `bot` и `applications.commands` + права из раздела [Права Discord](#права-discord).
4. На сервере: **Настройки сервера → Роли** — перетащите роль Mishanya **выше** ролей, которые бот должен выдавать,
   и выше участников, которых он должен модерировать.

## Файл .env

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `DISCORD_TOKEN` | токен бота | — (обязательно для работы бота) |
| `PANEL_PASSWORD` | пароль панели, минимум 8 символов | создаётся setup.bat |
| `OWNER_ID` | ваш Discord ID (только для информации в диагностике) | пусто |
| `PANEL_HOST` | адрес панели | `127.0.0.1` |
| `PANEL_PORT` | порт панели | `8777` |
| `ALLOW_REMOTE_PANEL` | разрешить `PANEL_HOST`, отличный от localhost | `false` |
| `OPEN_BROWSER` | открывать панель при запуске | `true` |
| `LOG_LEVEL` | подробность журнала | `INFO` |
| `SESSION_HOURS` | срок действия входа в панель | `72` |
| `DATA_DIR`, `BACKUP_DIR` | другие папки для базы и копий | `data`, `backups` |

Пример без секретов — `.env.example`. Файл `.env` исключён из Git (`.gitignore`).
Без токена панель всё равно запускается и показывает инструкцию.

## Запуск и остановка

- **Запуск**: двойной щелчок по `start.bat`. В одном процессе запускаются веб-панель и бот,
  база создаётся/обновляется автоматически, панель открывается в браузере: http://127.0.0.1:8777
- **Остановка**: закройте окно, нажмите `Ctrl+C` или запустите `stop.bat` (корректное завершение,
  через 15 секунд — принудительное).
- Журнал работы: `data\mishanya.log` (ротация, до ~8 МБ). Токен и пароль в журнал не пишутся — они маскируются.

Если порт занят, приложение сообщит об этом при запуске: смените `PANEL_PORT` в `.env`.

## Веб-панель

| Раздел | Что делает |
|---|---|
| Главная | статус бота и соединения, серверы, состояние базы, ошибки, последние события, основные настройки |
| Серверы | список серверов (иконка, ID, участники, связь, включённые модули); серверы, которые бот покинул, — с ручным удалением данных |
| Обзор сервера | статистика, состояние модулей, проблемы конфигурации (права бота, удалённые каналы/роли), последние события |
| Уровни и XP | все параметры начисления, формула с таблицей уровней, уведомления с предпросмотром, исключения, импорт/экспорт, сброс |
| Таблица лидеров | рейтинг с поиском и страницами, изменение XP/уровня, сброс участника |
| Роли за уровни | добавление, отключение, удаление наград; предупреждение, если бот не может выдать роль |
| Модерация | настройки, пороги авто-наказаний, список предупреждений (снятие), журнал случаев |
| Автомодерация | каждое правило с порогами, действиями и исключениями; наказание за повторные нарушения |
| Приветствия | вступление, выход, ЛС; текст + embed; предпросмотр |
| Автороли | роли для участников и ботов, исключения, задержка |
| Команды | префикс, список команд, редактор с предпросмотром |
| Журналы | просмотр и очистка событий, выбор событий и каналов, список напоминаний |
| Общие настройки | статус бота, хранение журналов, автокопии, создание/восстановление/удаление копий, синхронизация команд |
| Диагностика | токен, intents, задержка, целостность базы, права бота на каждом сервере, ошибки приложения |
| Справка | краткая инструкция |

Все переключатели и кнопки работают с backend: настройки проверяются на сервере (Pydantic) и сохраняются в SQLite.
Несохранённые изменения подсвечиваются панелью внизу (сохранить — кнопкой или **Ctrl+S**), опасные действия требуют подтверждения.
Если бот сейчас не подключён к серверу, настройки можно менять — они применятся после подключения.

Удобства интерфейса:
- выбор каналов и ролей — списки с поиском (каналы сгруппированы по категориям, недоступные боту роли помечены);
- переключение между серверами прямо в боковой панели, с сохранением текущего раздела;
- модули включаются и выключаются переключателями на странице обзора сервера;
- тема оформления: как в системе, светлая или тёмная (переключатель внизу боковой панели, запоминается в браузере);
- предпросмотр сообщений отображает Markdown Discord: **жирный**, *курсив*, __подчёркнутый__, ~~зачёркнутый~~, `код`, блоки кода, цитаты, заголовки, спойлеры, упоминания и ссылки;
- пока бот не настроен, на главной показывается чек-лист первых шагов.

## Резервное копирование и восстановление

- **Автоматически**: по умолчанию раз в 24 часа, хранятся 10 последних автокопий (настраивается в «Общих настройках»).
- **Вручную**: «Общие настройки» → «Создать копию». Копии лежат в папке `backups` (`mishanya-ДАТА-ВРЕМЯ-*.db`).
  Копия делается через SQLite backup API и согласована даже во время работы.
- **Восстановление из панели**: «Восстановить» у нужной копии. Перед заменой автоматически сохраняется
  страховочная копия текущей базы (`...-before_restore.db`).
- **Восстановление без запуска** (например, база повреждена и приложение не стартует): остановите Mishanya,
  запустите `restore.bat` и выберите копию. Повреждённый файл не удаляется, а переименовывается в `mishanya.db.corrupted-ДАТА`.
- Можно просто скопировать папку `data` (при остановленном приложении) — это полная копия всех данных.

## Обновление

**Автоматически.** Если Mishanya установлена через `git clone` и запущена через `start.bat`, она проверяет GitHub
**при каждом запуске** (до подключения к Discord; без интернета запуск не задерживается дольше 30 секунд), а затем
раз в 6 часов (настраивается). Найдя новую версию, создаёт резервную копию базы, загружает изменения
(`git pull --ff-only`), перезапускается и при необходимости сама доустанавливает зависимости Python.
Проверить и установить обновление вручную можно в панели: **Общие настройки → Обновления** (там же список изменений
и выключатель автообновления).

Для приватного репозитория git должен иметь доступ к GitHub без вопросов: достаточно один раз выполнить
`git pull` вручную и войти через окно Git Credential Manager — дальше пароль запоминается.
Если файлы программы изменены вручную, обновление не выполняется, чтобы не потерять правки.

**Вручную** (например, для установки из ZIP):
1. Остановите Mishanya и создайте резервную копию (или скопируйте папку `data`).
2. Выполните `git pull` (или замените файлы проекта новыми, **не трогая** `.env`, `data\` и `backups\`).
3. Запустите `setup.bat` — он обновит зависимости, а при первом запуске новая версия сама применит миграции схемы.
   Миграции только добавляют изменения и не удаляют данные.

## Безопасность

- Панель слушает только `127.0.0.1` — с других компьютеров она недоступна. Запросы с чужим заголовком Host
  отклоняются (защита от DNS rebinding). Открыть панель в сеть можно только осознанно: `PANEL_HOST` + `ALLOW_REMOTE_PANEL=true`
  (без HTTPS это небезопасно — используйте, например, VPN или обратный прокси с TLS).
- Вход по паролю из `.env`; сравнение в постоянном времени; после 5 ошибок — растущая блокировка.
- Сессия — случайный токен в HttpOnly-cookie с `SameSite=Strict`; в базе хранится только его SHA-256.
- Все изменяющие запросы требуют CSRF-токен в заголовке; CORS ограничен адресом панели; заголовки CSP, X-Frame-Options.
- Секреты не попадают во frontend, URL и журналы. Пользовательские команды и шаблоны не выполняют код
  (никаких `eval`/`exec`/`str.format`), импорт — только проверенный JSON.

## Права Discord

Ссылка-приглашение запрашивает: просмотр каналов, отправка сообщений (и в ветках), встраивание ссылок,
прикрепление файлов, чтение истории, добавление реакций, управление сообщениями, ролями, каналами и никнеймами,
кик, бан, тайм-аут (moderate members), просмотр журнала аудита, подключение и речь в голосовых каналах (музыка), перемещение участников (голосовые комнаты).
Если бот уже добавлен на сервер старой ссылкой, выдайте его роли права «Подключаться», «Говорить» и «Перемещать участников».
Можно выдать роль «Администратор» — тогда проверки прав бота всегда проходят, но ограничения иерархии ролей Discord остаются.

## Ограничения

Ограничения Discord:
- Бот не может управлять ролями и участниками **выше или на уровне своей высшей роли** и не может действовать на владельца сервера.
- Тайм-аут — максимум 28 дней; администратора отправить в тайм-аут нельзя.
- `/clear` и `/purge` удаляют сообщения старше 14 дней по одному — это медленно (ограничение API).
- Текст удалённого/изменённого сообщения доступен, только если сообщение было в кэше бота (отправлено после запуска, последние ~2000).
- Личные сообщения не доставляются, если участник их закрыл — бот это обрабатывает и продолжает работу.
- Новые/изменённые slash-команды синхронизируются глобально при запуске, только если они изменились (лимит Discord на синхронизации). Появление в клиенте может занять несколько минут; помогает перезапуск Discord (Ctrl+R).
- Rate limits Discord соблюдаются библиотекой discord.py; бот не делает бесконечных повторов.

Ограничения Mishanya (честно):
- Карточка `/rank` — это embed с текстовой полосой прогресса, а не картинка.
- Предпросмотр в панели отображает основной Markdown Discord, но упрощённо: упоминания показываются как текст (без настоящих имён), эмодзи сервера и вложенные списки не отрисовываются.
- `OWNER_ID` сейчас используется только для отображения в диагностике; доступ к панели защищён паролем.
- Опросы сделаны на реакциях (без встроенных опросов Discord).
- Бот работает, пока запущен ваш компьютер и `start.bat`. Пропущенные за время простоя напоминания доставляются после запуска; сообщения, отправленные, пока бот был выключен, XP не приносят.

## Решение проблем

- **`setup.bat`: «Failed building wheel for davey» / ошибки загрузки Rust.** Это пакет для голосовых каналов, и под
  вашу версию Python (обычно 3.15) ещё нет готовой сборки. Обновите Mishanya — новая версия `setup.bat` не пытается
  собирать его из исходников и продолжает установку без музыки. Чтобы музыка заработала, установите Python 3.14 и
  снова запустите `setup.bat`: он сам выберет 3.14 и пересоздаст окружение `.venv`.

| Проблема | Что сделать |
|---|---|
| «Python не найден» | установите Python 3.12+ с отметкой «Add to PATH», перезапустите setup.bat |
| Панель пишет «Токен бота не задан» | заполните `DISCORD_TOKEN` в `.env`, перезапустите |
| «Discord не принял токен» | токен неверный или сброшен — получите новый (Reset Token) |
| «не включены привилегированные intents» | включите Server Members и Message Content Intent в Developer Portal |
| «Порт … занят» | Mishanya уже запущена (откройте адрес панели) или порт занят другой программой — смените `PANEL_PORT` |
| Не выдаются роли / автороли | поднимите роль Mishanya выше; проверьте право «Управлять ролями»; смотрите «Диагностику» |
| Автомодерация не удаляет сообщения | нужно право «Управлять сообщениями»; модераторы не проверяются (отключаемо) |
| Нет slash-команд | подождите несколько минут, перезапустите Discord; «Общие настройки» → «Пересинхронизировать» |
| «База данных повреждена» | остановите приложение и запустите `restore.bat` |
| Забыли пароль панели | посмотрите или замените `PANEL_PASSWORD` в `.env`, перезапустите |
| «Неверный CSRF-токен» | обновите страницу панели |

## Для разработчика

Структура:

```
mishanya/            Python-пакет (один процесс: FastAPI + discord.py в одном event loop)
  main.py            точка входа, запуск/остановка, обработка ошибок старта
  config.py          чтение .env
  core.py            контейнер сервисов, журналирование с маскировкой секретов
  schemas.py         Pydantic-схемы настроек модулей (хранятся JSON в guild_configs)
  db/                модели SQLAlchemy, миграции (schema_version), backup/restore
  services/          бизнес-логика без Discord API (уровни, модерация, автомод, шаблоны, журналы…)
  bot/client.py      класс бота, intents, синхронизация команд, обслуживание (очистка, автокопии)
  bot/cogs/          модули бота
  api/               FastAPI: авторизация, маршруты, проверки состояния серверов
frontend/            React + TypeScript + Vite (готовая сборка в frontend/dist)
tests/               pytest (моки Discord API, API-тесты, запуск приложения)
scripts/             setup.py, restore.py
```

- Тесты: `.venv\Scripts\python -m pytest`
- Разработка панели: запустите `start.bat`, затем в `frontend` — `npm install` и `npm run dev`
  (Vite проксирует `/api` на `127.0.0.1:8777`). Сборка: `npm run build`.
- Новая миграция схемы: добавьте функцию в `MIGRATIONS` в `mishanya/db/database.py` со следующим номером версии.
- Новый модуль: Pydantic-схема в `schemas.py` + запись в `MODULES`, cog в `bot/cogs` и в списке `COGS`, страница в `frontend/src/pages`.

Принятые технические решения: SQLite + один процесс без Redis/Docker; настройки модулей — JSON с валидацией Pydantic
(легко расширять без миграций); вход по паролю вместо OAuth2 (проще и не требует открытого redirect URL);
Discord ID передаются в API строками (JavaScript теряет точность больших чисел).
